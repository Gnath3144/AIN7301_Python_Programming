# Week 2 — Data Structures and Pandas

This folder contains the live-coding materials for AIN7301 Week 2.

## Learning sequence
1. Week 1 assignment-readiness bridge: input, type conversion, operators, conditions, loops, functions, file handling, exceptions and debugging.
2. Lists and indexing/slicing.
3. Tuples and sets.
4. Dictionaries and nested dictionaries.
5. List comprehensions and set operations.
6. NumPy foundations.
7. Pandas Series and DataFrames.
8. Data inspection, cleaning, filtering, grouping and descriptive statistics.

## Working rules
- Type code during the live session; do not paste complete solutions.

- Use the supplied datasets in `data/` when they are added.
