# Week 1 Assignment Readiness Bridge

Week 1 topics that need additional practice will be revisited alongside Week 2:

- `input()` and type conversion (`int()`, `float()`, `str()`)
- Arithmetic, comparison and logical operators
- `if` / `elif` / `else`
- `for` / `while`, `range()`, `break` and `continue`
- Functions, parameters, arguments and `return`
- Lists and dictionaries as containers for sales records
- Reading CSV/text files, writing outputs and `with open(...)`
- `try` / `except` and common exceptions
- Debugging syntax, runtime and logic errors

The purpose is to close learning gaps without abandoning the Week 2 sequence. Students should keep progressing on the Week 1 Sales Analysis assignment while practising these concepts.
